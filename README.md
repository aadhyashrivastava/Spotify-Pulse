# Spotify-Pulse
Spotify Pulse is an interactive music analytics dashboard built using Microsoft Power BI, exploring streaming performance, artist popularity and audience metrics across 15 popular International and Indian artists. It is a data analytics project designed to compare the performance of selected artists through interactive visualizations. 

# Tools and Technologies:
1. Microsoft Power BI - dashboard development and visualization.
2. Power Query - Data extraction and transformation.
3. CSV - data storage and import.

# Data Sources:
- Streaming statistics - Kworb (third-party Spotify streaming statistics)
- Artist Metadata - Third party artist statistics sources
- Snapshot Date - 05 November 2026
  
These are third party statistics and snapshots, not official live Spotify data. Please refer to the original sources for their definitions and methodology. 

# Dashboard Features:
1. Streaming performance cards
2. Top 10 Most streamed songs
3. Daily Streaming leaders
4. Artist streaming share
5. Monthly listener distribution
6. Followers versus monthly listeners comparison
7. Global Artists ranking
8. Interactive artists slicer

# Artists Covered:
Taylor Swift, The Weeknd, Ariana Grande, Billie Eilish, Sabrina Carpenter, Ed Sheeran, Justin Bieber, Dua Lipa, Bruno Mars, Arijit Singh, Shreya Ghoshal, Gracie Abrams, Olivia Rodrigo, One Direction and BTS.

# Learning Outcomes:
1. Learned how to import data directly from web in Power BI.
2. Learned how to make dashboards interactive using slicer.
3. Learned how to transform data in Power BI.
4. Learned how to style and format visualizations.
5. Learned about Power query and DAX queries.

# Limitations:
1. This project covers a selected group of 15 artists, not the entire Spotify catalouge.
2. Streaming figures are third party statistics.
3. Artists metadata represent a dated snapshot and may change over time.
4. Collaboration tracks may appear under multiple artists.
